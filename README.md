# TP2 - Portfolio multipágina con React Router DOM

**Alumno:** Venturelli Cristhian Mathias
**Comisión:** 5

## Descripción
Continuación del portfolio del TP1. Ahora es una aplicación multipágina con un menú lateral (aprox. 30 % del ancho) y un área de contenido (aprox. 70 %) que cambia según la ruta, sin recargar la página.

| Página | Ruta |
|---|---|
| Inicio | `/` |
| Sobre mí | `/about` |
| Habilidades | `/skills` |
| Proyectos | `/projects` |
| Contacto | `/contact` |

## Tecnologías
React, Vite, React Router DOM, JavaScript (JSX) y CSS.

## Instalación
```bash
npm install
```

## Ejecución
```bash
npm run dev
```
Abrir http://localhost:5173
